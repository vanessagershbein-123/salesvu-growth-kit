# SalesVu Growth Kit

Free tools that SalesVu's reps use to give independent Mexican restaurants something useful on every call: **"Useful first. Invitations second."**

- `index.html`: **Kit de ventas**: WhatsApp follow-up generator, owner proposal image, call guide
- `regalos.html`: **Regalos**: online health check and lunch customers near you (MealPool), with a map, owner image and office flyers

Built by Vanessa Gershbein (McCombs+ x SalesVu, fall 2026). See [SCOPE.md](SCOPE.md) for the plan.

- [TEST-PLAN.md](TEST-PLAN.md): a 2-week A/B test SalesVu can run to see whether gifts get more owners to reply, with a log template ([test-log-template.csv](test-log-template.csv))
