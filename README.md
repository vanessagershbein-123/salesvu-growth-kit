# SalesVu Growth Kit

Free tools that SalesVu's reps use to give independent Mexican restaurants something useful on every call: **"Useful first. Invitations second."**

- `index.html`: **Kit de ventas**: WhatsApp follow-up generator, owner proposal image, customer promo card, call guide
- `regalos.html` *(in progress)*: **Regalos**: online health check, marketing kit, lunch customers near you

Built by Vanessa Gershbein (McCombs+ x SalesVu, fall 2026). See [SCOPE.md](SCOPE.md) for the plan.
